## 壹 · 基础篇

### 起卦咒

> 天清地灵，卦神有灵，
> 我今叩问，速显通灵，
> 明彰报应，诸事分明，
> 我布九宫，人间万事，与我速知。

等心平气和后，让缘主洗净手，洗牌三次，方可摆牌。

### 起卦方式

1. 将第一张牌放入中宫。
2. 从离卦开始顺时针摆两圈牌。
3. 摆完外八门后，在中宫放最后一张牌。
4. 让卦主从中宫左右两张牌中选择一张，与局中其他牌找对。
5. 只要牌的组合找回中宫，剩下的牌不管配没配齐，都算卦局起完，开始解卦。
6. 卦局中配了几对，又叫开了几门。

### 开门的应用

断任何事，只要有五门及以上没开，均主磁场紊乱：

- 问事主不稳定；
- 问人主在医院、火葬场、监狱等磁场不稳定之地；
- 或心乱如麻。

### 流星赶月定根法

**四柱起法**：

以离宫作为流星赶月的起点，轮数求测人或所测人的出生月份；从出生月份的落宫上顺数生日；从生日宫顺数生时；时宫起虚岁。无论男女一律顺起。

**起卦节点**：9、17、25、33、41、49、57、65。

**流月流日的计算方法**：

从虚岁上起月份，月份起日，日上起时，以此类推。与西北牌不同的是，东北牌查宫位不入中宫。

## 贰 · 应用篇

### 基本名词释义

| 名词 | 含义 |
|------|------|
| 中宫 | 卦的中央叫中宫，代表一个事情的旺衰程度，也代表当前的状态，有时也被取作事情的总体状态。如看财是正财还是偏财，以中宫定象。又叫做主卦、卦神（卦身）。 |
| 头顶脚踩 | 卦的离宫为头顶，又叫做身前、开路，一般主事情前一段时间的状态，或者上半段。卦的坎宫为脚踩，又叫做身后，一般主事情后一段时间状态，或者下半段。头顶脚踩在断初步吉凶时比较重要，需要着重参考。 |
| 四柱 | 流星赶月赶出的年月日时，代表事情的总体状态，在断事情的后续吉凶时极其重要。月日时可以用于看先天缘分，年宫代表此人一年的状态，作用相当于小运。 |
| 用神 | 既看什么事所取的那张牌。如看财取八万，看官司取四并。 |
| 追宫赶宫 | 用神的前一位叫追，用神的后一位叫赶。追宫代表什么带来的这件事，或者主动找到这件事的因素；赶宫代表这件事情中会遇到什么，或是这件事的运转中自己会遇到的因素。 |
| 牌头 | 即牌面字头的方向。头朝外为阳、为远、为外部、为不认识的人、为出；头朝内为阴、为近、为内部、为认识的人、为入。 |

### 断卦基本思路

1. **一看主卦为当前状态**。主卦坐四并、二条、一并、二并为衰；中宫坐五并、红花、八万、毛鱼、三并为旺。主卦不代表吉凶，只代表当前状态。五并占中：主动的事办事主自己走不动，不好走。
2. **二看头顶脚踩为初步吉凶**。头顶主事情的前一段状态，脚踩为事情的后一段状态。头顶脚踩全吉为旺，一吉一凶为平，双凶为衰。
3. **三看用神上不上柱**。用神坐四柱、头顶、脚踩、主卦为上柱，不坐为不上柱，不上柱说明事情不动，如占感情对方不上卦，说明无缘，占财财不上卦，说明事情还没开始，没有落实，所以没钱。
4. **四看四柱卦势旺衰**。旺为好，衰为坏。坐四并二条为空，为不成；坐一并为小人拦路；坐二并为病气；坐小鱼、八万、红花、三并为顺为好；坐五并为自己知道，无吉无凶。

问事主卦既是用神的情况下：一看头顶脚踩，二看年月日时。年月日时占得不好，也代表结果不成。

### 辅助判断

中宫的牌也可以与用神牌生克：

- 用神牌克中宫牌为凶，自己被克住了不好办。
- 自身克用神牌为吉，代表自己能压得住事。
- 自身生用神牌为凶，代表自己劳心费力，要投入，要花钱。
- 用神生自身牌为吉，代表事主动来找人。
- 自身与用神比和吉，事来旺我。

生克仅作为辅助判断，不可用于判断结果，也不是特别重要。

### 特殊格局

- 翻开就是一对，且头一张朝里一张朝外，特殊格局以上面那张为准。颠倒一般主不稳定，有变化，不属于吉。
- 如求财，财星上面一张头向外，下面一张向内，代表财先进后出。
- 断小人，一并一张向里，一张向外，主内外都有小人。多个小人先内后外主先好后坏，问求财先进后出，求贵人主先答应帮忙，后面又不答应帮忙了。先外后内主先坏后好，问求财主先出后进，求贵人主麻烦，要多求几次才能答应。

### 流月、流日与应期的判断方式

1. **流月**以流年宫为起始点，依次向下排。如流年宫在离，正月也在离，五月在坎，十二月在乾，以此类推。也可从流月上起流日，流日起流时，以流月所到的宫上的牌论断吉凶。
2. **应期**以时辰宫为起始点。问几日内的事，直起流日，不起流月；问几月内的事，不起流年，只起流月。详推可从流月、流日宫为起点往下数。一般问流月取流年宫，问事取时辰宫。

## 小结

1. 理气篇以起卦咒、起卦方式、开门应用为基础，强调五门以上不开则磁场紊乱。
2. 九星各有固定卦位、五行与类象，并配有九星神项诀，用于取象与神煞参考。
3. 流星赶月定根法用于起四柱，节点为9、17、25、33、41、49、57、65，查宫位不入中宫。
4. 应用篇以中宫、头顶脚踩、四柱、用神为断卦骨架，先看主卦状态，再看头脚吉凶，三看用神上柱，四看四柱旺衰。
5. 辅助判断看中宫与用神生克，仅作参考，不决定结果。
6. 流月以流年宫起，应期以时辰宫起；问近起近，问远起远。
