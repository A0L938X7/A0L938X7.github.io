一、设计理念
================================================================================

本系统以「纸感古籍 + 现代阅读」为核心设计理念，追求：

  · 温和、克制、留白
  · 米黄纸底，类宣纸质感
  · 汉字优先，宋体与齐伋体并用
  · 一处红（朱砂）点睛，不做多色喧哗
  · 昼夜双色，暗色不做纯黑，仍保留纸感

命名系统：
  · 太极（Taiji）——旋转图标
  · 齐伋体（Qiji）——标题专用字体
  · 宋体（Serif）——正文
  · 朱砂（Accent）——唯一强调色

五、组件清单（Components）
================================================================================

5.1 头部（header）

  · 高度：最小 56px，sticky top
  · 组成：太极 SVG + 品牌名 + 导航栏 + 汉堡按钮 + 主题按钮
  · 边框：底部 1px solid var(--border)
  · 层级：z-index 100

5.2 太极图标（.taiji-icon）

  · 尺寸：32×32
  · 动画：24s 线性无限旋转
  · 由 5 个 SVG 元素构成：圆、半月、上圆、下圆、两个小圆点

5.3 导航栏（.navbar）

  · 桌面端：横向，每个按钮高 56px，右边框分隔
  · active：背景 var(--btn-primary-bg)，文字 var(--btn-primary-text)
  · 移动端（≤820px）：隐藏，改用 .mobile-nav

5.4 图标按钮（.icon-btn）

  · 尺寸：36×36
  · 边框：1px solid var(--border-3)
  · 用途：汉堡、主题切换

5.5 按钮（.btn）

  · 主按钮：实底、深色底、白字
  · 幽灵按钮（.btn.ghost）：白底、深字、灰边
  · 小号（.btn.mini）：padding 8px 14px

5.6 侧边栏（.sidebar）—— 学习模块 / 小测

  · 宽 280px
  · 背景 var(--bg-soft)
  · 右边框 1px solid var(--border)
  · 三栏布局下与中间、右侧各自独立滚动
  · 搜索框（.sidebar-search-wrap）：sticky top，固定于侧边栏顶部
  · 分组（.tree-folder）：可折叠，箭头旋转动画 0.25s
  · 列表项（.tree-list li）：左 2px 透明边框，active 时变朱砂
  · 悬浮：padding-left 微右移 4px，背景 bg-card

5.7 内容区（.content-area）

  · padding 32px 40px 64px
  · 滚动：overflow-y auto，scroll-behavior smooth
  · h1：30px 齐伋体 字距 5px
  · h2：21px 齐伋体 字距 4px，下方 1px 边框
  · h3：17px 500
  · p：15px / text-2 / 行高 2
  · table：全宽，th 背景 var(--bg-panel)
  · 引用块：左 3px 边框 + 软底
  · 代码：等宽字体，软底 + 边框

5.8 提示框（.callout）—— Markdown 引用块的特殊渲染

  · 触发条件：引用块第一行为 **标题**
  · 背景 var(--accent-soft)
  · 左边 3px 朱砂
  · padding 14px 18px
  · 标题 .callout-title 加粗朱砂

5.9 知识图谱（.graph-svg）

  · 位置：右侧栏上方固定（panel-block.graph-block）
  · 容器：正方形，aspect-ratio 1/1，max-height 240px
  · viewBox：0 0 280 280
  · 节点：圆 r=20（中心）/ r=16（普通）
  · 连线：贝塞尔曲线
  · active：朱砂填充
  · 节点标签：默认 opacity:0，悬浮或 active 时显示
  · 交互：拖拽平移、滚轮缩放、点击跳转

5.10 本页大纲（.outline-list）

  · 位置：右侧栏下方（panel-block.outline-block）
  · 独立滚动，scroll-behavior smooth
  · 三级缩进：lv2 / lv3 / lv4
  · 悬浮：朱砂 + 左移 + 背景

5.11 小测卡片（.quiz-card）

  · 横向 flex，两端对齐
  · 边框 1px solid var(--border)
  · 状态徽标（.quiz-card-status）：边框框，done 时朱砂

5.12 小测题目（.quiz-question）

  · 题号：朱砂，齐伋体
  · 选项（.quiz-options li）：flex，字母圆圈 + 文字
  · selected：朱砂边 + 朱砂浅底
  · correct：绿色 / wrong：红色

5.13 成绩环（.score-ring）

  · viewBox 160×160
  · 半径 r=66
  · stroke-width 12
  · 旋转 -90deg
  · 中心显示百分比

5.14 排盘盘面（.pan / .gong）

  · 3×3 网格，gap 6px
  · 每格 aspect-ratio 1/1
  · 宫名：左上 15px
  · 卦性大字：居中 60px，半透明
  · 牌：竖排 4 行（顺序 3,1,0,2）
  · 终身盘：4×4 网格，中心 2×2 合并

5.15 活盘卡片（.live-card）

  · 140×140
  · 索引：左上
  · 牌值：28px
  · 宫位：13px 底部

5.16 提示条（#toast）

  · 固定底部居中
  · 半透明黑底白字

六、动效（Motion）
================================================================================

  太极旋转       24s linear infinite
  主题切换       0.2s background / color
  导航按钮       0.12s background
  侧边栏项悬浮   0.15s + padding-left 0.2s cubic-bezier(.16,1,.3,1)
  侧边栏折叠     0.25s grid-template-rows + opacity
  图谱节点悬浮   0.18s fill / stroke
  图谱标签显隐   0.18s opacity
  大纲项悬浮     0.15s + padding-left 0.2s cubic-bezier(.16,1,.3,1)
  移动菜单       0.26s cubic-bezier(.16,1,.3,1)
  汉堡旋转       0.22s
  成绩环         0.6s stroke-dashoffset
  toast          0.25s all

原则：
  · 所有过渡 ≤ 0.3s，只有太极是长动画
  · 不使用弹跳、抖动等夸张缓动
  · 主缓动曲线 cubic-bezier(.16,1,.3,1)（"ease-out-expo"风格）
  · 折叠展开用 grid-template-rows 0fr↔1fr 实现精确高度动画

七、昼夜模式（Dark Mode）
================================================================================

切换机制：
  · 类名 body.dark 切换
  · localStorage 键：xiangma-learn-theme
  · 首选项：saved === 'dark' || (saved !== 'light' && prefersDark)
  · 排盘页 Shadow DOM 通过 host.classList.add('dark') 同步

颜色原则：
  · 背景不做纯黑，用 #121212
  · 文字不做纯白，用 #e8e8e8
  · 朱砂在暗色下提亮为 #ff7675
  · 链接蓝在暗色下提亮为 #74b9ff
  · 纸感保留：暗色仍属"深墨纸"，非"纯黑屏"

九、Markdown 渲染风格对照
================================================================================

本系统的 md 渲染严格对齐原始单文件版本的美术风格：

  | Markdown 语法       | 渲染结果                                |
  |---------------------|----------------------------------------|
  | # 标题              | 30px 齐伋体 字距 5px                    |
  | ## 标题             | 21px 齐伋体 字距 4px + 下 1px 边框       |
  | ### 标题            | 17px 500 字距 1px                       |
  | #### 标题           | 15px 600 text-3 色                      |
  | 段落                | 15px / text-2 / 行高 2                  |
  | **粗体**            | 600 / text 主色                         |
  | *斜体*              | 朱砂色，非真斜体                        |
  | `代码`              | 等宽 + 软底 + 边框                      |
  | 表格                | th 背景 bg-panel，td/th 1px 边框        |
  | > **标题** 引用     | 朱砂 callout（特殊渲染）                |
  | > 普通引用          | 左 3px 边框 + 软底，text-3 色           |

原则：所有渲染结果必须使用 CSS 变量，确保昼夜模式自动适配。

十、可访问性与兼容性
================================================================================

可访问性：
  · 图标按钮有 title 属性
  · 颜色对比符合 WCAG AA（浅色下）
  · 暗色下朱砂提亮，保证可读
  · 未做完整键盘导航，可扩展

兼容性：
  · 无外部 CSS / JS 依赖，纯原生实现
  · 图片仅一张 jiang.jpg，onerror 降级为文字头像
  · 字体为本地字体，未安装时自动回退楷体
  · 离线可用（除 md / xml 需 HTTP 服务外）
  · 排盘页用 Shadow DOM 隔离，不受主文档 CSS 影响

浏览器要求：
  · Chrome / Edge / Firefox / Safari 现代版本
  · 需要支持：fetch、DOMParser、URLSearchParams、CSS 变量
  · 排盘页需要支持：Shadow DOM、attachShadow
