================================================================================
第一部分  设计理念
================================================================================

本系统以「纸感古籍 + 现代阅读」为核心设计理念，追求：

  · 温和、克制、留白
  · 米黄纸底，类宣纸质感
  · 汉字优先，宋体与齐伋体并用
  · 一处红（朱砂）点睛，不做多色喧哗
  · 昼夜双色，暗色不做纯黑，仍保留纸感

命名系统：
  · 太极（Taiji）——旋转图标
  · 齐伋体（Qiji）——标题专用字体
  · 宋体（Serif）——正文
  · 朱砂（Accent）——唯一强调色

5.6 左侧栏（.sidebar）—— 学习模块 / 小测

5.7 中间内容区（.content-area）

  · 引用块内多行用 <br> 拼接，逐行独立显示

5.8 提示框（.callout）

  · 触发：Markdown 引用块第一行为 **标题**

  · 标题 .callout-title 加粗朱砂
  · 正文多行同样逐行 <br> 拼接

5.9 翻页按钮（.module-nav）

  · 位置：正文之后，48px 上边距，上方 1px 分隔线
  · 布局：两端对齐，左「上一节」右「下一节」
  · 按钮：幽灵按钮样式（.btn.ghost）
  · 首/末节显示 disabled 按钮（已是第一节 / 已是最后一节）
  · 单按钮 max-width:46%，超出省略号
  · 不进入右侧「本页内容」大纲

5.10 Hero Image（.note-hero）

  · 位于笔记顶部，可选（learn.xml 的 hero 属性）
  · 贴边显示（负 margin 抵消 content-area padding）
  · 最大高度 320px（移动端 220px）
  · object-fit: cover，不拉伸
  · 降饱和 filter 处理，暗色下压暗
  · 图片 404 时整个 hero 区隐藏

5.11 知识图谱（.graph-svg）

  · 位置：右侧栏上方固定
  · 容器：正方形，aspect-ratio 1/1，max-height 240px
  · 布局：力导向（斥力 + 弹簧 + 向心 + 阻尼）
  · 节点尺寸：根 r=10，一级 r=5.5，二级+ r=4
  · 节点颜色：
    - 根节点：朱砂填充
    - 非根节点：朱砂实线边框（stroke-opacity:.85）
    - 悬浮/激活：朱砂浅底 + 1.8px 加粗边框
    - 已废弃：虚线边框（v2.2 起移除）
  · 文字：默认 opacity:0，悬浮或 active 时显示
  · 节点链接化：用 SVG <a> 包裹，href="learn.html?note=<id>"
    - 右键可复制链接
    - 中键 / Ctrl+点击 新窗口打开
    - 普通左键由 JS 接管（单击跳转，双击展开）
  · 交互：
    - 拖拽节点：单个节点自由拖拽，其他节点响应
    - 拖拽空白：平移
    - 滚轮：缩放
    - 单击：跳转笔记
    - 双击：展开/收起关联
    - 悬浮：聚焦（其他节点变暗，相连边变红加粗）

5.12 图谱悬浮聚焦（v2.2 新增）

  · 触发：mouseenter 节点
  · 状态类：.graph-viewport.has-hover
  · 效果：
    - 悬浮节点：加 .hovered，保持正常亮度
    - 相连的边：加 .hovered，朱砂红、1.6px、不透明
    - 相邻节点：加 .hovered，保持正常亮度
    - 根节点：始终 .hovered（不被压暗）
    - 其他节点：opacity .25
    - 其他边：opacity .15
  · 退出：mouseleave，移除所有 .hovered 和 .has-hover

5.13 本页大纲（.outline-list）

  · 位置：右侧栏下方，独立滚动
  · 三级缩进：lv2 / lv3 / lv4
  · 悬浮：朱砂 + 左移 + 背景

5.14 小测卡片（.quiz-card）

  · 横向 flex，两端对齐
  · 边框 1px solid var(--border)
  · 状态徽标（.quiz-card-status）：边框框，done 时朱砂

5.15 小测题目（.quiz-question）

5.16 成绩环（.score-ring）

5.17 排盘盘面（.pan / .gong）

第六部分  动效（Motion）
================================================================================

  太极旋转       24s linear infinite
  主题切换       0.2s background / color
  导航按钮       0.12s background
  侧边栏项悬浮   0.15s + padding-left 0.2s cubic-bezier(.16,1,.3,1)
  侧边栏折叠     0.25s grid-template-rows + opacity
  图谱节点悬浮   0.15s fill / stroke / stroke-width / stroke-opacity
  图谱聚焦过渡   0.18s opacity
  图谱标签显隐   0.15s opacity
  图谱力导向     逐帧 requestAnimationFrame
  翻页按钮悬浮   0.15s background / border-color / color
  大纲项悬浮     0.15s + padding-left 0.2s cubic-bezier(.16,1,.3,1)
  移动菜单       0.26s cubic-bezier(.16,1,.3,1)
  汉堡旋转       0.22s
  成绩环         0.6s stroke-dashoffset
  toast          0.25s all

原则：
  · 所有过渡 ≤ 0.3s，只有太极是长动画
  · 不使用弹跳、抖动等夸张缓动
  · 主缓动曲线 cubic-bezier(.16,1,.3,1)
  · 折叠展开用 grid-template-rows 0fr↔1fr 实现精确高度动画
  · 力导向动画由 JS 逐帧驱动，不走 CSS transition
  · 图谱聚焦用 opacity 过渡，平滑不刺眼

第七部分  昼夜模式（Dark Mode）
================================================================================

切换机制：
  · 类名 body.dark 切换
  · localStorage 键：xiangma-learn-theme
  · 首选项：saved === 'dark' || (saved !== 'light' && prefersDark)
  · 排盘页 Shadow DOM 通过 host.classList.add('dark') 同步

颜色原则：
  · 背景不做纯黑，用 #121212
  · 文字不做纯白，用 #e8e8e8
  · 朱砂在暗色下提亮为 #ff7675
  · 链接蓝在暗色下提亮为 #74b9ff
  · 纸感保留：暗色仍属"深墨纸"，非"纯黑屏"

第九部分  Markdown 渲染风格对照
================================================================================

本系统 md 渲染严格对齐原始单文件版本的美术风格：

  | Markdown 语法       | 渲染结果                                |
  |---------------------|----------------------------------------|
  | # 标题              | 30px 齐伋体 字距 5px                    |
  | ## 标题             | 21px 齐伋体 字距 4px + 下 1px 边框       |
  | ### 标题            | 17px 500 字距 1px                       |
  | #### 标题           | 15px 600 text-3 色                      |
  | 段落                | 15px / text-2 / 行高 2                  |
  | **粗体**            | 600 / text 主色                         |
  | *斜体*              | 朱砂色，非真斜体                        |
  | `代码`              | 等宽 + 软底 + 边框                      |
  | 表格                | th 背景 bg-panel，td/th 1px 边框        |
  | > **标题** 引用     | 朱砂 callout（特殊渲染）                |
  | > 普通引用          | 左 3px 边框 + 软底，text-3 色           |
  | > 多行引用          | 逐行 <br> 拼接，每行独立显示            |
  | ![图](img/x.png)    | 自适应宽度图片                          |

原则：所有渲染结果必须使用 CSS 变量，确保昼夜模式自动适配。

第十部分  可访问性与兼容性
================================================================================

可访问性：
  · 图标按钮有 title 属性
  · 颜色对比符合 WCAG AA（浅色下）
  · 暗色下朱砂提亮，保证可读
  · 图谱节点已链接化，可右键复制链接
  · 未做完整键盘导航，可扩展

兼容性：
  · 无外部 CSS / JS 依赖，纯原生实现
  · 图片仅一张 jiang.jpg，onerror 降级为文字头像
  · 字体为本地字体，未安装时自动回退楷体
  · 离线可用（除 md / xml 需 HTTP 服务外）
  · 排盘页用 Shadow DOM 隔离

浏览器要求：
  · Chrome / Edge / Firefox / Safari 现代版本
  · 需要支持：fetch、DOMParser、URLSearchParams、CSS 变量、requestAnimationFrame、SVG
  · 排盘页需要支持：Shadow DOM、attachShadow
  · 图谱链接需要支持：SVG <a> 元素（现代浏览器均支持）
