## 一、六亲总论

### 1. 五类六亲

六爻以卦宫五行为“我”，按生克关系排出五类六亲：

| 关系 | 六亲 |
|---|---|
| 生我者 | 父母 |
| 同我者 | 兄弟 |
| 我生者 | 子孙 |
| 克我者 | 官鬼 |
| 我克者 | 妻财 |

出处：【聊天06-03】P2-11；【千金赋】P91-93。

### 2. 京房六亲取用式

京氏曰：

- 八卦鬼为系爻。
- 财为制爻。
- 天地为义爻。
- 福德为宝爻。
- 同气为专爻。

对应：

| 京房名 | 六亲 | 含义 |
|---|---|---|
| 义 | 父母 | 万物本源，生我者 |
| 专 | 兄弟 | 血缘同源，同我者 |
| 宝 | 子孙 | 受父母庇护，我生者 |
| 制 | 妻财 | 我克者，被我制伏 |
| 系 | 官鬼 | 克我者，束缚我者 |

出处：【曜贞课程】P169-170；【高源】P29-33；【曜贞古法】P29-33。

### 3. 真六亲与假六亲

- 本宫卦的六亲所透出到飞神的六亲，为真六亲。
- 其余卦的六亲，为假六亲。
- 用神不现，取伏神。
- 伏神不现，用飞宫法。
- 飞宫法：如：生世为父，父克为母，生父为爷，爷克为奶。（详见后续飞宫飞数部分内容）
- 和父相比，子和亥为外亲。
- 合世同者，为同辈。
- 我生为子孙，子克为儿媳。

出处：【高源】P29-33；【曜贞古法】P29-33。

### 4. 六亲生克关系

- 父母生兄弟，兄弟生子孙，子女生妻财，妻财生官鬼，官鬼生父母。
- 父母克子孙，子孙克官鬼，官鬼克兄弟，兄弟克妻财，妻财克父母。

出处：【聊天06-03】P2-11；【千金赋】P7-9。

### 5. 六亲为本，六神为末

- 六亲是根本，六神是枝末。
- 吉凶得失，以六亲为主。
- 六神只可推演事情性质状态。
- 神煞又为末中之末。

出处：【千金赋】P97-104。

## 十四、练习

1. 找十卦，标出五类六亲。
2. 判断每卦六亲真假。
3. 用飞宫法取六亲。
4. 看六亲发动、空亡、入墓。
5. 用六亲断婚姻、求财、疾病各三例。
6. 整理六亲临六神组合象。



> 六亲为本，六神为末。  
> 六亲象是六爻取象的骨架。  
> 先明六亲，再论六神、神煞。
